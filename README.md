# CSE476-Final-Project
ASU CSE476 final project, which is about implementing a reasoning agent using a provided ASU LLM API.  

How to Reproduce My Results
To reproduce my results, first install the required dependencies by running "pip install requests". Next, make sure the necessary API environment variables are set, including OPENAI_API_KEY="cse476", API_BASE="http://10.4.58.53:41701/v1", and MODEL_NAME="bens_model". Ensure that the file cse_476_final_project_test_data.json is located in the same directory as the scripts. You must also be connected to the ASU network or using the ASU VPN. Once everything is set up, run python generate_answer_template.py to generate the outputs.
