# CSE476-Final-Project
ASU CSE476 final project, which is about implementing a reasoning agent using a provided ASU LLM API.  

How to Reproduce My Results
Step by Step:
Install Dependencies
Pip install requests
Ensure API Environment Variables
export OPENAI_API_KEY="cse476"
export API_BASE="http://10.4.58.53:41701/v1"
export MODEL_NAME="bens_model"
Ensure there is a cse_476_final_project_test_data.json in the same folder
Be connected to the ASU network or via ASU VPN
Run python generate_answer_template.py
